# 🐍 100 Days of Python Coding Challenge 🚀

## Welcome to My Journey!

This repository documents my progress as I take on the **#100DaysOfCode challenge** with a focus on Python. My goal is to build a strong habit of coding daily, deepen my understanding of Python, and create a portfolio of small projects and exercises.

---

### What's Inside?

You'll find a daily log of my work, organized into folders for each day. Each folder might contain:

-   Solutions to coding problems (from platforms like LeetCode, HackerRank, etc.)
-   Small scripts and personal projects.
-   Notes on new concepts, libraries, or frameworks I'm learning.
-   Code from tutorials or courses I'm following.

---

### My Commitment

1.  **Code daily:** I will code for at least one hour every day for the next 100 days.
2.  **Public log:** I will push my progress to this GitHub repository every day.
3.  **Track progress:** Each day's folder will contain the code and a brief summary of what I worked on.
